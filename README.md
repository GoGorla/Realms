# Hollowmark
Static game, no build step. Upload this whole folder to a GitHub repo and enable Pages (Settings > Pages > main / root).
- `index.html` page shell
- `css/style.css` look
- `js/data.js` items, mobs, structures, balance numbers
- `js/game.js` game logic
- `assets/classes.png` class sprite sheet (6 sprites, 100px each: Knight, Sorcerer, Orc, Druid, Rogue, Barbarian)
Replace any file to update the game. Saves live in the browser (localStorage).
