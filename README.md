# Realms.io (Plains)
A florr.io-style top-down survival game. Open `index.html` (or host with GitHub Pages: Settings > Pages > main branch).
- Accounts + saves use browser localStorage (demo only, no server).
- 6 classes with perks; locked until you reset progress (Pouch menu).
- Controls: WASD or hold mouse to move, K skills, U upgrade, P pouch, E interact (shops `$`, village chests), Esc close.
